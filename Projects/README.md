# Full-Portfolio-1-7

A collection of data analytics and machine learning projects.

---

## Projects

### [Project-Two – Gold Price Forecasting with Geopolitical Risk](Project-Two/)
Forecasts next-day gold prices using historical market data and geopolitical risk indices. Includes time-series feature engineering, an XGBoost regression model (R² = 0.91), and an interactive Streamlit dashboard.  
**Stack:** Python · XGBoost · Streamlit · Pandas · Tableau

---

### [Project-Three-II – E-commerce RFM Analysis v2 (SQL + Tableau)](Project-Three-II/)
End-to-end pipeline that generates synthetic 2025 e-commerce data, runs RFM segmentation with SQLite CTEs, and publishes an interactive heatmap to Tableau Public. Identified 4,000+ VIP customers and measured a 20% avg order lift from promo codes. An updated iteration featuring an improved Tableau data model (Relationships instead of Blends), revenue-encoded heatmap coloring, and a detailed setup guide.  
**Stack:** Python · SQLite · Tableau Public

---

### [Project-Four – Retail Sales KPI Dashboard (Excel BI)](Project-Four/)
Interactive Excel BI dashboard built on 17,000+ retail transactions (2023–2025). Tracks Revenue, Gross Margin %, Average Order Value, and YoY growth across channels, regions, and product categories using PivotTables and Slicers.  
**Stack:** Microsoft Excel · Power Query · PivotTables

---

### [Project-Five – Online Retail Customer Churn Prediction](Project-Five/)
Machine learning project that predicts online retail customer churn and surfaces the key drivers behind it using Python data analytics.  
**Stack:** Python · Scikit-learn · Pandas

---

### [Project-Six – Statistics Foundations & A/B Testing](Project-Six/)
Applies foundational statistics and hypothesis testing to real A/B test data, analyzing conversion results across countries and user segments.  
**Stack:** Python · Statistics · A/B Testing

---

### [Project-Seven – Ecommerce Power BI Report](Project-Seven/)
Power BI project with a semantic model and report built on e-commerce data, covering sales performance, customer behavior, and product analytics.  
**Stack:** Power BI · DAX
