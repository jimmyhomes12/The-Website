# Project-Two – Gold Price Forecasting with Geopolitical Risk

Forecasts next-day gold prices using historical market data and geopolitical risk indices. Includes time-series feature engineering, an XGBoost regression model (R² = 0.91), and an interactive Streamlit dashboard.

**Stack:** Python · XGBoost · Streamlit · Pandas · Tableau
